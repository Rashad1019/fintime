# Fincent Work Log

**Dates covered:** October 31 and November 1, 2026
**Live site:** https://fintime.streamlit.app
**Code:** https://github.com/Rashad1019/fintime
**Latest live commit:** `7f456ea`

## Where it stands

Fincent is a public learning page for ordinary people who just heard about a stock or fund. A visitor enters a ticker and sees what it is, how it has done, whether it looks like a good time to buy, and what famous investor styles would do.

- All 174 automated tests pass.
- The live page loads and IVV shows its plain buy answer.
- I have not confirmed the new short persona answers on the live site with a real AI reply.

## What changed

### Correct numbers (October 31)

- **Dividend yields:** fixed for any ticker. Yahoo's reported figure was wrong for some funds, so yields now come from actual payouts.
- **Currency and share counts:** fixed for foreign stocks such as TSM, including the backup data sources.
- **Live backups:** corrected FMP and the Yahoo chart source, because the live site runs on those when the Yahoo library fails.
- **10-year yield and inflation:** these now use sources that work on the live site.
- **Garbled text:** dollar signs no longer break the page's formatting.

### A page for ordinary people (November 1)

- The home page now follows one order: what it is, how it has done, is now a good time, key numbers, then the investors.
- An AI-written plain explanation appears under "What it is".
- The past month is the default timeframe, and other timeframes are one click away.
- The Watchlist and Quote pages were removed.

### Original look restored

- The first rebuild changed too much, so these came back: the "Read the market. Know the business." header, the blue design, the full-width layout, the sidebar menu, and the Agents page.
- The yellow theme was removed.
- The header text changed from "twenty" to "sixteen" investor frameworks, to match the real count.

### Easier to use

- A visible menu with Dashboard, Analytics, and Agents appears whenever the sidebar is closed, including on phones.
- No ticker is filled in on any page. A ticker typed on one page carries to the others.
- Investors are chosen from one short dropdown, grouped by category, instead of a long list.
- Every ticker starts with no investors picked and no answers. Old saved answers no longer load.
- Loading is now visible: a pop-up, a running count, and a line for each investor.

### How the investors answer

Each investor tries these in order:

| Try | Model | Time allowed |
|---|---|---|
| 1 | Gemma (free) | 30 seconds |
| 2 | Gemma (paid) | 1 minute 30 seconds |
| 3 | Claude Haiku 5.5 (paid) | 1 minute 30 seconds |
| 4 | GPT-6 Luna (paid) | 2 minutes |

- A financial joke appears when an investor reaches the last try.
- If nobody can answer, the page says the network is busy.
- The longest possible wait is about 5 and a half minutes.
- The "What it is" explanation uses a shorter limit, so it can't hold up the page for long.

### Written for everyday readers

- **Should I buy today?** now appears at the top of the "Is now a good time?" section, with prices to watch from the chart.
- Investor answers are limited to about 100 words, in four parts: My take, My move, Why, and What could go wrong.
- Verdicts are now Buy now, Wait, or Skip.
- The persona note now reads: "Inspired by how famous investors think. These aren't the real people, and this isn't financial advice."

### Cleanup

- Removed local-only files, which saved about 383 MB.
- Removed `CHANGELOG.md`. It stopped at July 6 and described pages that no longer exist.

## Problems and how they were fixed

| Problem | Cause | Fix |
|---|---|---|
| Live numbers stayed wrong after a fix | The live site uses backup data sources | Fixed the backups too |
| Personas kept running | Not confirmed. Either a stuck model, or slow answers one after another | Time limits and running investors at the same time |
| "Investors could not be reached" | Probably my own 40-second limit. The page hid the exact error | Replaced with the try order above |
| Answers already showing on a ticker | Saved runs were shared across the whole site, and picks carried over | Answers now stay with one visitor and one ticker |
| `AttributeError` on every ticker | Streamlit kept an old code file in memory after a push | Forced a clean restart |
